## Ruang Bumi

## Deskripsi
Web yang dirancang untuk mengedukasi dan mengajak pengguna menjaga kelestarian lingkungan melalui kebiasaan sehari-hari. 

## Tujuan Pengujian
Pengujian dilakukan untuk memastikan bahwa proyek:
- Berfungsi sesuai kebutuhan
- Memiliki antarmuka yang mudah digunakan
- Berjalan dengan performa yang baik
- Aman digunakan
- Bebas dari kesalahan kritis

---

# Testing Checklist

## 1. Fungsionalitas

### Hasil yang Diharapkan
Seluruh fitur utama dapat berjalan sesuai spesifikasi.

### Checklist
- [x] Verifikasi simulasi berhasil dijalankan
- [x] Verifikasi responsif 


### Prioritas
**Tinggi**

---

## 2. Antarmuka Pengguna (UI)

### Hasil yang Diharapkan
Tampilan mudah dipahami dan seluruh elemen dapat digunakan dengan baik.

### Checklist
- [x] Seluruh tombol dapat diklik
- [x] Navigasi antar halaman berjalan lancar
- [x] Tampilan responsif pada berbagai ukuran layar


### Prioritas
**Sedang**

---

## 3. Kinerja (Performance)

### Hasil yang Diharapkan
Aplikasi dapat merespons dengan cepat dan stabil.

### Checklist
- [x] Waktu pemuatan halaman sesuai target
- [x] Penggunaan memori tidak berlebihan
- [x] Tidak terjadi crash saat penggunaan normal

### Prioritas
**Tinggi**
